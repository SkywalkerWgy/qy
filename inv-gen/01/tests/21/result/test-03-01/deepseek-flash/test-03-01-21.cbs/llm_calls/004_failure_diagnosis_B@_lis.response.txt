[Failed Property]
establishment of i_13: the invariant must hold before the first loop iteration from the incoming program state.

[Failure Cause]
The WP goal instantiates i_13 for an arbitrary p with 0 <= p < outer_i. The available outer-loop invariant i_3 only states that for every q < p with arr[q] < arr[p], we have dp[p] >= dp[q] + 1. It does not provide the required converse/existential witness: if dp[p] > 1, there must be some q < p with arr[q] < arr[p] and dp[p] == dp[q] + 1. Therefore, from i_3, i_2, and the initialization facts, one can only derive lower bounds on dp[p], not the equality-or-existence disjunction needed by i_13. The inner loop B has not yet run for the current outer index, and it only modifies dp[i], so it cannot establish the property for p < i.

[Responsible Scope]
both

[Refinement Direction]
The failed invariant i_13 is not non-inductive with respect to the inner loop body, because B does not modify dp[p] for p < i. The failure is establishment from the incoming outer-loop state. The A@_lis invariants are too weak: they do not expose the missing existential/equality fact that each already processed dp[p] is either 1 or is exactly obtained from some valid predecessor q via dp[p] == dp[q] + 1. The refinement must make that missing fact available from the outer-loop summary; it cannot be recovered from the current A@_lis invariants or from boundary contracts.
